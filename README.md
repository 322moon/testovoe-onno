## Запуск

Нужен JDK 21. Команды выполнять из корня проекта.

```bash
./gradlew bootRun
```

- Адрес: http://localhost:8080/ui
- Логин: `admin`
- Пароль: `admin`
- Остановка: `Ctrl+C`
- База данных: `data/subscriptions.mv.db`

## Работа

1. **Справочники → Клиенты**: создайте клиента, укажите имя.
2. **Справочники → Тарифы**: создайте доступный тариф, например 100 ₽ за 30 дней.
3. **Документы → Платежи**: выберите клиента, укажите 1000 ₽ и способ оплаты. Сохраните и проведите платёж.
4. **Документы → Подписки**: выберите клиента, добавьте тариф на 2 периода. Дата начала подставится автоматически. Сохраните: итог — 200 ₽, окончание — начало плюс 60 дней. Проведите подписку.
5. **Отчёты → Остатки лицевых счетов**: остаток клиента — 800 ₽.
6. **Отчёты → Выручка по тарифам**: выручка — 200 ₽, периодов — 2.

Сохранение документа не меняет остатки и выручку. Движения создаются при проведении.
При недостатке денег проведение отклоняется.

Для изменения проведённого документа сначала нажмите **«Отменить проведение»**.
Для отмены подписки нажмите **«Отменить подписку»** в списке или на форме, укажите причину и подтвердите.
Причина сохраняется в документе. Если подписка проведена, проведение снимается автоматически.
Списание и выручка отменятся. Проведение отменённой подписки движений не создаёт.

**Отчёты → Дашборд**: выберите период для поступлений, выручки, числа периодов и диаграмм.
Последние платежи и подписки показываются за всё время.

Статусы подписок обновляются раз в минуту. Дата окончания — первый день, когда подписка уже не действует.

```bash
./gradlew clean check bootJar

```

```bash
java -jar build/libs/testovoe-onno-0.0.1-SNAPSHOT.jar \
  --server.port=8081 --spring.datasource.url=jdbc:h2:file:./data/demo
```
